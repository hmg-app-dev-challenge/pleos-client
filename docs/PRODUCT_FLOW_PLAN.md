# 차Park v2.1.1 화면과 사용자 흐름

기록 카드의 명칭과 서사는 ‘내 차와 보낸 하룻밤 기억’으로 통일한다. 기존 7단계의 종료 화면은 별도의 기록 결과 화면으로 확장한다. 주행 중 화면은 단계 번호에 관계없이 배터리·내비 상태 중심의 읽기 전용 화면이다. 상세 비교·입력·체크 및 밤 배경 연출은 비활성화하며 정차 복귀 시 작성 내용을 보존한다. 사용자 주차 확인 버튼만으로 차량 주행 신호나 플랫폼 제한을 해제하지 않는다.

## 주요 상호작용 원칙

- 조건 변경 시 준비 항목의 수량·이유가 달라지면 해당 체크를 해제한다. 같은 의미의 체크는 유지한다.
- 미확인 항목이 남아도 출발하는 기존 팝업을 제거한다. 현장 확인을 출발 전에 체크하도록 강제하는 대신 단계별 체크를 나눈다.
- 충전소 경유를 요청했는데 단독 목적지만 안내되면 경유 포함 성공으로 표시하지 않는다. 경유를 빼고 진행하려면 사용자가 변경 내용을 확인한다.
- 정확한 출발 시각은 검증된 이동·충전 시간으로 계산할 때만 표시한다. 그 외에는 일몰 전 도착 권장으로 제한한다.
- 일몰·일출 계산과 실제 관람/도착 기록을 구분한다. 조망 미확인 장소에 바다 방향 일치 등의 문구를 만들지 않는다.
- 차량 값 출처 라벨은 유지하고 시연 배너·개발 진단·값 조작 UI는 노출하지 않는다. 실제 사용의 실패·미지원·정보 없음은 숨기지 않는다.
- 밤 모드는 시스템 차량 설정을 바꾸는 기능이 아니라 앱 화면 테마다. 직접 제어·자동 복원 완료를 표시하지 않는다.
- 새 여행은 지난 기록을 보존하고 누락 준비물을 가져온다. 기존 여행 초기화와 기록 삭제를 같은 행동으로 묶지 않는다.

## v2.1.1 추가 화면 기준

- 시작 화면은 금요일·회사 주차장으로 사용자를 고정하지 않는다. 토요일 집 앞에서 가족 3명이 계획하는 대표 흐름도 자연스럽게 지원한다.
- 완료 카드는 장소명·날짜·풍경, 확인 조건, 충전 판단, 출발/철수 SOC, 계산/실제 사건 타임라인과 다음에 챙길 것을 한 장으로 구성한다. 과거 조사 정보는 당시 스냅샷으로 표시한다.
- 설정·지난 기록·삭제 확인·입력창·선택 탭도 라이트/다크/따뜻한 밤 색상을 따른다. 주행 전환 시 모달 상세 조작과 밤 연출을 잠그되 초안은 보존한다.
- 배터리 명시적 미지원이면 시작·준비·요약·주행·기록 화면의 배터리 표현과 충전 검토를 일관되게 처리한다. 과거에 실제 수집된 기록은 삭제하지 않는다. 권한/연결 실패를 미지원으로 바꾸지 않는다.
- R14 예상 사용시간은 핵심 화면에 placeholder 숫자를 넣지 않는다. X1~X3의 지원·데이터·모델 검증 후 별도 정차 화면을 검토한다.

## 대표 시나리오 인수 기준

가족 3명·취사 선택 → 야간 화장실 미확인 후보의 확인 필요 표시 → 조건이 확인된 바다 × 일몰 장소 선택 → 사용자 기준 미만 SOC에 충전 검토 → 침구 수량·간편식 안내 → 짐 싣기 체크 → 충전 경유 포함 내비 → 주행 읽기 전용 → 도착·주차 → 수면 밤 모드 → 일출 이후 철수 → 기록 카드 → 다음 여행의 빠뜨린 준비물 우선 표시.

같은 시나리오에서 SOC 미지원/권한 부족, 장소 결과 없음, 내비 실패, 시간 정보 누락, 통신 끊김을 각각 검증한다. 원문의 예시 시각을 하드코딩하지 않는다. 모든 장소·시간·출처는 해당 데이터의 확인 수준을 따른다.
