# 차Park MVP 화면과 사용자 흐름 — PRD v0.2

2026-11-14 · **목표 흐름**. 앱 0.4.0의 7단계는 아직 변경되지 않았다. 기능은 [PRD](reference/CHAPARK_MVP_PRD_V0_2.md), 시각 디자인은 기존 현대차 Pleos 시스템, 실제 변경 순서는 [개발 계획](IVI_WORK_PLAN.md)을 따른다.

## 홈과 사용자 진행 5단계

| 구분 | 화면 구성·정보 | 주요 행동·진입 관문 |
| --- | --- | --- |
| 홈 (번호 없음) | 차량 SOC/출처/갱신·오류·미지원, 진행 중 여행 요약 | 여행 없음: 새 차박 시작 / 진행 중: 이어하기를 주 CTA로 표시. 새 여행은 별도 확인, 기존 기록 보존 |
| 1 차박 계획 `PLANNING` | 같은 화면 조건 영역+3곳 장소 비교. 공간이 좁으면 조건/장소 2탭, 사용자 단계 추가 없음. 인원·취사 3종·철수 시각·SOC 기준·날짜, 장소 조건/충전/풍경/확인일 | 이 장소 선택. 조건 유효·선택 장소 보존 후 출발 준비. 오늘 날짜 기본은 새 여행에만 적용 |
| 2 출발 준비 `PREPARING` | 지난 누락 우선, 챙길 것/출발 전 할 일/현장 할 일. 수량·필수·이유·누락. SOC 미만일 때 충전 검토·연결 후보 선택 | 준비 완료. 출발 대상 필수 항목 전체 완료+날짜/시간 유효. 선택 누락은 기록, 필수 누락은 완료 아님. 현장 항목은 나중에 확인 |
| 3 이동 `MOVING` | 진입 시 목적지/선택 경유지 최종 확인. 내비 전환 후 앱 복귀 시 여행 요약. 요청/탐색/안내/실패는 내부 상태 | 차량 내비게이션 시작. 실제 안내 확인 후 기본 내비 전환. 복귀·정차 확인 후 도착했어요. 실패는 주소·재시도/경유 재선택 |
| 4 차박 `STAYING` | 도착 확인 후 주차·현장 조건 확인, 공조/실내등/환기/문 잠금/개인 물품 정리. 수면·밤 상태 | 수면 준비 완료→철수 시작을 내부 상태에 따라 순차 노출. 조회 못 한 항목은 사용자 직접 확인. 밤 화면은 Pleos 가독성 유지 |
| 5 철수와 기록 | 차량 설정 원복·장비 회수·쓰레기·놓친 물품·장소 상태, 누락 준비물. 종료 후 한 장의 기억 | 철수 완료→로컬 저장 성공 후 기록·새 여행 시작. 체크 중에는 completed=false; 기록을 별도 진행 단계로 세지 않음 |

조건/장소 상세·출처는 계획 화면 내부 패널 또는 보조 동작으로 다룬다. SDK 초기화 화면이나 독립 주행 지도를 만들지 않는다. 주요 행동은 화면 상태별 하나, 출처·다른 장소 비교·뒤로 등은 보조 위계다.

## 기존 상태 보존

기존 step 0/1/2/3/4/5/6을 홈/계획/계획/준비/이동/차박/철수·기록으로 연결한다. 도착·주차·수면 준비·completed 플래그에 따라 내부 상태를 복원하며 번호만 줄여 과거 완료 여부를 바꾸지 않는다. 이전 bool 취사와 누락된 새 필드는 재확인이 필요한 이전 정보로 보존한다. archive의 과거 출처/시각/체크를 새 규칙으로 다시 쓰지 않는다.

계획 변경으로 의미·수량·이유가 바뀐 준비 항목만 체크를 해제한다. 새 여행의 날짜/체크/내비 상태는 이전 여행과 분리하고 명시적 누락 준비물과 미확인 정보를 구분해 이월한다. 앱 재시작 복원은 기존 수준 이상으로 유지한다.

## 주행·오류·출처

- 실제 주행 신호와 Car UX 허용은 별개다. 주행/불명/UX 제한 중 하나라도 있으면 요약만 제공하고 조건·비교·체크·모달·밤 연출을 잠근다. 사용자 주차 체크로 제한을 풀지 않는다.
- 내비 요청 성공을 안내 시작으로 표시하지 않는다. 목적지/경유 불일치나 좌표 0,0은 검증 대기·실패·명시적 사용자 확인으로 처리하고 자동 성공으로 숨기지 않는다.
- SOC 숫자는 유효한 값만, SDK/에뮬레이터/직접 입력 출처와 정상 수신 시각을 표시한다. 실패는 0%로 바꾸지 않는다. 명시적 미지원 수동 입력 정책은 [D-06](MVP_PRD_V0_2_REVIEW.md)에서 관리한다.
- 충전 검토 자동 노출은 유효 SOC < 기준만. SOC가 갱신되어 카드가 사라져도 이미 선택한 경유지를 조용히 지우지 않는다. 최종 경로 확인에서 유지/해제를 명시한다.
- 장소 UNKNOWN은 확인 필요다. 공개 출처 열람일과 현장 조망 조사일을 구분한다. 근거 없으면 화장실/취사/조망을 확정하지 않는다.
- 계산된 일몰·일출과 실제 도착·철수 시각은 기록에서 구분한다. 시간 미확보는 일몰 전 도착 권장, 계산 실패는 해당 정보만 미제공이다.
- 시연·개발 조작 UI는 노출하지 않는다. 출처 라벨은 유지한다. 오류 안내는 원인과 다음 행동을 제공한다.

## 디자인 고정 조건

기존 Pleos의 색상·Asta Sans·타입·큰 터치 영역·버튼/선택/팝업과 상태별 토큰을 사용한다. PRD를 이유로 새로운 팔레트나 스마트폰식 세로 폼을 추가하지 않는다. ‘따뜻한 낮은 대비’ 대신 기존 Dark의 읽기 가능한 텍스트 대비와 검증한 밤 확장을 사용한다. 좁은 창·큰 글자에서도 필수 정보와 CTA가 잘리지 않는지 확인한다. 원본 컴포넌트가 없는 기억 카드·시간 배경은 앱 확장으로 표시한다.

## 대표 인수 흐름

정차 홈 → 같은 계획 화면에서 3명·COOKING·철수 시각·SOC 기준·날짜와 장소 3곳 비교 → 근거가 있는 서해안 일몰 후보 → 취사 불가에 식사 변경·매트 3개/침구 3세트·기준 미만 SOC에 충전 검토 → 짐 필수 체크 → 경유 최종 확인·실제 내비 전환 → 앱 복귀 시 요약/주행 잠금 → 정차 도착·주차/현장 확인 → 수면·밤 → 필수 철수 → 출발/철수 SOC·누락·선택 경유/내비 결과·계산 사건 기록 → 다음 여행 누락 우선.

현재 실제 장소 자료에는 이 대표 조건이 모두 확보되지 않았다. 자료 조사와 release 전체 흐름 검증을 끝내기 전 인수 완료로 표시하지 않는다. 이전 7단계 흐름은 [이력](history/20261114_before_mvp_prd_v02/PRODUCT_FLOW_PLAN.md)에 보존한다.
