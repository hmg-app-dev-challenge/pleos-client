# 차Park 제품 경험 중심 프로토타입 개편

2026-11-11 · 폰 `:app` / IVI `:ivi` 공통 기준

## 변경 원칙

사용자 요청에 따라 화면은 실제 서비스의 언어와 작업 순서로 구성한다. 데모 데이터의 출처와 SDK 미연결 범위는 개발 문서·테스트에서 관리한다. 사용자 화면에는 시연 배너, 가상/데모 표기, SDK 진단, 배터리 조작, 응답 성공/실패 주입, 주행 제한 재현을 노출하지 않는다.

기존 `IVI_DEMO_GUIDE.md`의 운영 방식은 이 문서로 대체한다. 원본 Pleos 폰트·색상·컴포넌트 치수와 폰/IVI별 레이아웃은 유지한다.

## 구현 단계 — 완료

1. 공통 데이터·문구: 장소를 서비스명·소개로 표현하고 규칙의 개발용 설명 제거.
2. 공통 여정: 폰도 `:shared`의 상태 머신을 사용. 도착/주차 분리, 수면·철수 체크 및 완료 기록 일치.
3. 제품 화면: 개발용 UI 제거, 배터리는 읽기 전용 표시. 설정은 테마·새 여행만 제공.
4. 이동 흐름: 이동 시작 → 로컬 데이터 준비(비동기) → 이동 중 → 사용자 도착 확인 → 사용자 주차 확인. 응답 조작 버튼 없음.
5. 수면·철수: 차량 기본 설정을 직접 확인하는 자연스러운 체크리스트. 자동 제어·복원 성공을 표시하지 않음.
6. 검증: 양 앱 전 과정·체크 관문·복원, 화면 내 개발용 용어 부재, IVI 좁은 창×양 테마, SDK 별도 프로브.

## 사용자 흐름

| 단계 | 사용자 행동 | 화면 결과 |
| --- | --- | --- |
| 시작 | 오늘 밤 차박 시작 | 현재 여행·배터리·조건 요약 |
| 조건 | 인원·조리·반려동물·침낭 선택 | 필요한 준비 조건 저장 |
| 장소 | 쉼터 비교·선택 | 장소 운영 조건과 예상 기온 |
| 준비 | 항목 확인 후 이동 | 미확인 항목은 확인 팝업 제공 |
| 이동 | 이동 시작 | 준비 후 자동으로 이동 중 화면, 차량 내비에서 경로 확인 안내 |
| 도착 | 도착했어요 → 주차했어요 | 주차 확인 후 수면 준비 진입 |
| 수면 | 네 가지 확인 | 모두 확인하면 다음 날 철수로 |
| 철수 | 네 가지 확인 → 차박 종료 | 종료 확인 후 완료 기록 |

반복 사용은 `설정 → 새 여행 계획 → 처음부터`. 종료 후 `새 여행 준비`는 사용자 조건과 테마 유지.

## 내부 구현 범위

장소·배터리·거리·기온은 로컬 fixture를 유지한다. 자동 이동 정보 준비는 로컬 비동기 처리이며 실제 길 안내 요청·위치 추적이 아니다. 도착·주차는 사용자 확인이다. 실제 SDK 읽기 프로브는 기기 테스트에서 수행하며 제품 화면에서 호출하지 않는다. 차량 쓰기 API는 없다.

IVI DataStore 영속 저장은 유지한다. 폰은 SavedStateHandle로 Activity/시스템 상태 복원을 지원하며 강제 종료 이후의 영속 보장은 후속이다. 실제 플랫폼 UX 미확인 시 IVI 상세 조작 잠금은 유지한다. 에뮬레이터 debug 실행만 로컬 프로토타입 흐름을 허용한다.

## 검증 기록

최종 실행 결과와 화면은 `verification/product/`에 저장한다. 이전 `verification/prototype/`는 개편 전 증거로 유지한다.


### 최종 결과

- 공통/폰/IVI JVM 테스트 19개 통과.
- Pleos 에뮬레이터 기기 테스트: IVI 7개, 폰 3개 통과. 폰 UI는 같은 에뮬레이터에서 390×844 고정 뷰포트로 7단계·완료×Light/Dark 검수했다. 별도 물리 폰 검증은 아니다.
- 폰·IVI 사용자 화면에서 `시연/데모/가상/재현/SDK/미연동` 문구 부재를 검증했다.
- IVI 800×1000 좁은 창×Light/Dark, 실제 앱 창 1682×1210에서 흐름·하단 버튼 검수.
- IVI 강제 종료 뒤 완료 기록 복원 확인. 폰 Activity 재생성 뒤 진행·완료 상태 복원 확인.
- 양 APK 빌드 성공. Lint: 폰 오류 0/경고 8, IVI 오류 0/경고 9(고정 버전·targetSdk 안내).
- 실제 SDK 별도 프로브: Vehicle/NaviHelper READY, capability READ, 원시 SOC 100. 이 값은 제품의 로컬 SOC에 합치지 않는다.
