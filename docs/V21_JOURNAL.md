# 여행 확인 시각과 이동 기록

2026-11-12 · v2.1 A1/A2 및 F1/F2의 기록 기반을 구현했다.

## 구현 범위

IVI에서 실제로 수락된 준비·수면·철수 체크 변경과 출발 준비 완료, 길 안내 요청/상태 확인, 도착, 주차, 여행 완료를 기록한다. 체크 해제도 false로 보존하며 준비 항목의 당시 제목·이유를 기록한다. 조건 변경에 의해 현재 체크가 무효화되더라도 과거 확인 기록 자체를 수정하지 않는다. 과거 확인 이력과 현재 유효한 체크 상태는 별개다.

시간은 앱이 관측한 epoch millisecond다. 사용자 확인과 SDK 이벤트를 origin으로 구분하며 차량 센서 발생 시각으로 주장하지 않는다. 안내 재연결은 새 물리적 출발이 아니므로 같은 안내의 중복 관측 기록을 추가하지 않는다. 중복 완료·도착·변화 없는 이벤트는 기록을 늘리지 않는다.

출발 준비 완료와 철수 완료에는 당시 앱이 보유한 배터리 값·출처·선택적 수신 시각을 함께 보존한다. 현재 제품 SOC는 예시이므로 기록에도 예시로 표시한다. 실제 SOC 스냅샷 연결은 B1/B2 이후 작업이다. 출발 준비 완료 기록은 실제 차량 출발 감지가 아니다.

저장 스키마 4는 활성 기록을 저장하고 완료 시 여행 ID별 보관본을 같은 DataStore 갱신에서 생성한다. 새 여행이나 활성 여행 초기화는 완료 보관본을 지우지 않는다. 이전 스키마의 상세 기록은 빈 목록으로 남기며 과거 시각을 만들어 채우지 않는다. 완료 화면에서 기록과 시간대·출처를 확인할 수 있다.

## 검증

- JVM 30개 통과: 공유 17, 폰 7, IVI 6. 새 테스트는 체크 의미 보존·무효 이벤트 무시, 안내 재연결 중복 방지, 도착 출처 구분, 완료 SOC/출처/수신 시각 보존을 검사한다.
- 관련 IVI 기기 테스트 4개 통과: 실제 안내 관측 기록과 완료 기록 1건, 보관본 존재, 다른 활성 여행 저장 후 기존 완료 보관본 유지, JSON 왕복 및 이전 데이터의 빈 이력, 좁은 창 양 테마.
- IVI APK 빌드·Lint 오류 0. 제품 폰 화면은 이번 단계에서 변경하지 않았으며 기기 회귀를 재실행하지 않았다.

## 남은 작업

완료 기록 목록·개별 상세·삭제 UI, 장소 근거/규칙의 전체 스냅샷, 누락 준비물과 다음 여행 연결, 태양 사건, 서버 동기화는 남아 있다. 현재 보관은 로컬 DataStore 기반이며 장기 이력의 Room 이전과 데이터 보관 정책은 후속이다. F1/F2 전체 완료로 표시하지 않는다. 실제 주행/정차 신호 검증과 SOC 단위·구독은 별도 관문을 유지한다.
