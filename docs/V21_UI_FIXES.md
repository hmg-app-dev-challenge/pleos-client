# 4단계 진행 및 테마 글자색 수정

2026-11-12

## 재현과 원인

실제 에뮬레이터에서 4단계 준비 계획의 출발 체크는 8/8이지만 여행 날짜가 없는 상태를 확인했다. `canDepart`는 날짜와 다음 날 철수 시각까지 요구하므로 버튼이 비활성이었다. 체크 완료 안내만으로 이동 가능하다고 설명하던 문구도 부정확했다.

설정·기록·확인 팝업은 메인 Surface 밖에 있어 테마의 기본 본문색이 전달되지 않았다. 또한 다크모드에서도 Material lightColorScheme 기본값을 사용해 입력창 등의 일부 색상이 라이트 값으로 남았다. 밤 테마의 선택 색상은 글자색이 순백색인지로 다크 여부를 판정하고 있었다.

## 변경

- 4단계에서 누락된 날짜를 명시적으로 설정할 수 있는 버튼과 날짜/시간대/철수 예정 표시 추가. 체크와 날짜가 필요하다는 안내로 수정.
- 버튼 위에 날짜 누락, 유효하지 않은 일정, 미확인 항목 수 등 진행 불가 사유 표시. 날짜 설정 후 기존 체크를 유지한다. 자동 날짜 채움이나 준비 관문 우회는 하지 않는다.
- IVI와 폰 공통 테마에서 LocalContentColor 지정. 라이트/다크 ColorScheme 기반 선택, IVI 입력창 보조색·테두리색 매핑.
- 밤 테마도 어두운 배경으로 인식해 선택 탭·토글·비활성 배경 적용.
- 기록·삭제 팝업 뒤에서 시스템 Back이 여행 단계를 바꾸지 않도록 처리.

## 검증

- JVM 30개 통과, 폰/IVI debug 빌드 성공.
- 기기 회귀 테스트 4개 통과. 날짜 없는 체크 완료 상태 → 날짜 설정 → 5단계 이동, 체크 보존 확인.
- 라이트/다크/밤 설정·기록·삭제 팝업의 실제 TextLayoutResult 글자색 검증.
- 라이트/다크 입력창과 밤 모드 선택 글자색 검증.
- 라이트/다크 7단계의 800dp 창 버튼 배치 확인.
- 실제 기기 화면 캡처 확인. 테스트는 임시 UI 상태를 사용하므로 사용자 여행 기록을 초기화하지 않았다.
