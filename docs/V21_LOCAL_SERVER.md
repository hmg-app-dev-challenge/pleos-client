# v2.1 로컬 서버·기록 연동 작업

2026-11-12. 사용자가 기존 서버 없음과 로컬 개발 서버 진행을 확인했다. 외부 서버 배포는 수행하지 않았다.

## 구현과 검증

- Python 표준 라이브러리 + SQLite 기록 API. loopback 바인딩, 로컬 Bearer 인증, 1 MB 요청 제한.
- IVI 완료 기록과 삭제 목록을 DataStore에서 재전송. 동일 내용 중복 저장 방지, 다른 내용 충돌 감지, 삭제 tombstone으로 재등록 방지.
- 서버 연결 대기와 기록 충돌을 구분한다. Coroutine 취소는 연결 실패로 삼키지 않는다.
- 서버 테스트 3개 통과: 인증, 입력 검증, 재전송·충돌·삭제 보존.
- Pleos 기기 테스트 5개 통과: 진입 1, 저장 2, 실제 서버 동기화 1, 전체 사용자 흐름 1.
- `shared:test`, `ivi:testDebugUnitTest`, debug 앱·테스트 APK 빌드 통과.
- 전체 흐름 테스트는 SDK 안내를 확인하며, 도착/주차는 사용자의 확인으로 진행한다. 자동 이동·자동 도착 증거는 아니다.

증거: [진입·저장](verification/v21-completion/entry-store.txt), [서버 동기화·전체 흐름](verification/v21-completion/sync-flow.txt), [SOC 20%](verification/v21-completion/soc20.txt).

## 함께 반영된 구현

DataStore 스키마 5, 지난 여행 조회/삭제, 누락 준비물과 다음 여행 재안내, 휴식/수면/별 보기 선택, 따뜻한 밤 테마, NOAA 근사 일몰·일출·방위 계산 표시, 공용 SDK SOC 공급자를 추가했다. 태양 계산의 독립 기준값 대조와 테마 전체 시각 검수, SOC 변경 구독 연속 검증은 남아 있다. 단일 SOC 20% 확인만으로 B1 전체 완료를 주장하지 않는다.

에뮬레이터 debug 주행 제한 우회를 제거하고 실제 Car UX 상태를 사용한다. 정차 상태에서 전체 흐름 통과를 확인했으나 주행→신호 불명→정차 전환 행렬은 추가 검증 대상이다.

## 남은 범위

G1/G2 전체는 부분 완료다. 장소/규칙 API와 활성 계획 revision 동기화, 서버 기록 다운로드 병합, 앱 종료 중 재전송은 미구현이다. 현재 단일 사용자 개발 서버와 전경 IVI 동기화만 제공한다. [서버 실행·API 계약](../server/README.md)을 참고한다.

충전소 경유(D2), 시간 정보(D4), 장소 속성별 근거(C1/C2), 태양 계산 기준값·배경(E1/E3), 전체 release 인수(H1/H2)도 아직 완료되지 않았다. Pleos 기술 지원 문의 초안은 발송하지 않았다. 모든 프로토타입 완료 또는 배포 완료로 해석하지 않는다.
