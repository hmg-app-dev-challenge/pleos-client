v2.1 첫 개발 묶음을 구현했다. 3명 이상 인원·침구 수량, 사용자 배터리 기준, 다음 날 철수 시각, 출발/현장 체크 분리와 저장 스키마 2를 적용했다. 이어서 여행 날짜·시간대·여행 ID와 저장 스키마 3를 구현했다. 이어서 확인/이동 사건 기록·스키마 4 저장·완료 여행 보관과 완료 화면 타임라인을 구현했다. [기록 작업](V21_JOURNAL.md) 참조. 전체 동기화 계약은 후속이다. [일정 작업 기록](V21_SCHEDULE.md)을 참조한다. [첫 단계 작업 기록](V21_STAGE_A.md)을 참조한다.

## 기존 테스트 결과

내비 연동 시점 JVM 21개·IVI 기기 8개 통과, IVI Lint 오류 0/경고 9. [최종 IVI 기기 로그](verification/navigation/ivi-tests.txt), [내비 연동 상세](NAVIGATION_INTEGRATION.md). 폰 기기 3개는 이전 제품 흐름 검증 결과이며 이번 문서 개정에서 재실행하지 않았다.

현재 내비 화면은 경로선·회전 안내를 표시하지만 배경 지도 타일이 회색이다. 자동 이동 재생과 실차 검증은 완료하지 않았다. 위 테스트를 v2.1 신규 요구의 합격으로 계산하지 않는다.
