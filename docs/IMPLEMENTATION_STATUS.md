# 차Park 구현 현황

2026-11-14 · 기획 v2.1.1 + MVP PRD v0.2 · IVI 앱 **0.5.0 (3)**. [개발 계획](IVI_WORK_PLAN.md), [단계별 실행](V2_1_1_EXECUTION.md), [최종 인수 범위](V2_1_1_ACCEPTANCE.md)를 함께 본다. 폰 버전과 범위는 이번 IVI 배포와 별도다.


## 0.5.0 현재 상태

5단계와 홈 이어하기, 취사 3종, 준비 기준 명시 확인·누락·수량, 수면 6개/철수 5개, 자동 일몰 밤 화면, 불변 기록 요약을 구현했다. SOC capability·수동값·실패 상태를 분리하고 P단+UX 허용으로 조작을 제한한다. schema 11은 이전 저장 1~10을 읽는다. Navi 요청 반환과 안내 관측을 분리하며 0,0 경유 좌표는 사용자 확인을 요구한다. 복수 풍경·추천 시간·조망 방향은 출처와 확인 기한을 검증한다.

검증·APK·미완료 조건의 현재 기준은 [0.5.0 인수 기록](MVP_V0_2_ACCEPTANCE.md)이다. 대표 조건 3곳의 운영/조망 근거, 실차 권한·단절·EV 잔여시간, 새 AVD 전체 인수는 미완료다. 아래 0.4.0 표와 후속 날짜별 메모는 실행 이력으로 보존한다.
