## 검증 기록과 한계

- [로컬 서버·기록 동기화](V21_LOCAL_SERVER.md): JVM 30개, 서버 3개, 진입/저장/동기화/전체 흐름 기기 5개 기록. 도착·주차는 사용자 확인이며 자동 주행 검증이 아니다.
- [UI 회귀](V21_UI_FIXES.md): 4단계 날짜 누락 복구·체크 보존, 세 테마 팝업 글자색, 입력값·밤 선택색, 두 테마 7단계 좁은 창. 기기 회귀 4개 통과. 사용자 기록 유지.
- [공개 SOC 20%](verification/v21-completion/soc20.txt): 단일 수치 검증. 연속 구독 변화나 모든 차종의 지원 증거로 확대하지 않는다.
- [에너지 접근 진단](EV_PROPERTY_REVIEW.md): 에뮬레이터 VHAL 등록과 앱 읽기 권한을 구분. 두 AAOS 속성 직접 읽기 성공 증거가 아니다.
- [기존 내비 연결](NAVIGATION_INTEGRATION.md): 단일 목적지 기반. 충전소 경유 성공 증거가 아니다.

서로 다른 시점의 시험 수치를 합쳐 v2.1.1 전체 통과로 보고하지 않는다. 이번 문서 개정에서는 시험을 재실행하지 않았다.
