# MVP PRD v0.2 반영·차이 검토

2026-11-14 · 사용자 첨부 [원문](reference/CHAPARK_MVP_PRD_V0_2.md) · 비교 기준 코드 `8a3e3b0`, IVI 0.4.0, DataStore 스키마 6. 이번 변경은 문서와 개발 계획이며 앱 수정·재시험 완료가 아니다.

## 적용 우선순위

1. 사용자의 이번 요청: PRD를 개발 계획에 반영하되 **디자인 요구사항은 기존 현대차 Pleos 디자인 시스템을 따른다**.
2. MVP 기능·제출 범위는 PRD v0.2, 장기 제품 방향은 기획 v2.1.1을 따른다. 기존 구현과 시험 증거는 보존하되 새로운 인수 통과로 간주하지 않는다.
3. 원문의 ‘AI 구현 지침’, 공개 전환·업로드·메일 제출 체크리스트는 문서 내용이다. 코드 변경, 외부 연락, 저장소 공개, 배포의 별도 실행 명령으로 취급하지 않는다.

Pleos 색상·Asta Sans·타입·간격·컨트롤·상태별 색과 터치 치수를 재사용한다. PRD의 5단계·가로형 비교는 기능/정보 구성으로 반영하지만 새로운 시각 스타일을 도입하지 않는다. ‘낮은 대비의 따뜻한 색상’은 본문 대비 저하로 적용하지 않는다. 승인된 Light/Dark 토큰과 가독성이 우선이며, 따뜻한 배경은 기존 확장으로 한정한다. 원본 전체 재조회는 이번 문서 작업에서 수행하지 않았다.

## 충돌·모호성 처리

| 쟁점 | 계획에서 적용할 처리 |
| --- | --- |
| 홈 포함 7단계 vs PRD 5단계 | 사용자 진행은 5단계로 변경. 내부 step을 유지/변환하더라도 기존 여행과 archive를 보존. 홈은 번호 없음 |
| COMPLETED의 진입/철수 표현 | 화면상 ‘철수와 기록’은 철수 체크 중에도 접근하되 데이터 `completed=true`는 필수 철수 후에만 설정. 화면 단계와 완료 사실을 분리 |
| F-02 ‘장소 보러 가기’ vs 통합 화면 | 같은 계획 화면 내 장소 영역/탭 이동으로 해석. 새로운 진행 단계로 만들지 않음 |
| §3 재진입 복원 필수 vs F-02 재시작 복원 선택 | 이미 구현된 영속 복원을 유지. 데이터 보존·내비 복귀 요구를 약화하지 않음 |
| F-01 미지원 직접 입력 vs 이전 카드 숨김 | 차량 Capability 미지원은 유지. 계획안은 미지원 안내+SOC 없이 진행, 정차 시 명시적 수동 입력 선택. 입력한 값만 MANUAL로 표시하고 SDK 지원으로 승격하지 않음. D-06은 0.5.0에서 미지원 수동 입력 허용으로 적용 |
| 필수 체크 vs ‘챙기지 못함’ | 누락을 완료로 계산하거나 우회 출발 허용하지 않음. 선택 항목 누락은 기록 후 진행, 필수 누락은 조건/계획 변경 또는 준비 완료가 필요. 면제 정책은 PRD에 없어 도입하지 않음 |
| 인원은 수량 전용 vs 기존 추가 잠자리 규칙 | 차량 정원·취침 가능 인원 판정 금지. PRD에 없는 인원 기반 추가 관문은 MVP에서 제외 대상으로 검토하고 일반 확인 문구와 분리 |
| Car UX 허용 vs 실제 정차 | UX 허용을 곧바로 `isDriving=false`로 변환하지 않음. 차량 신호 계약을 확인하고 둘 중 제한/불명이면 잠금. 사용자 ‘주차’ 버튼은 잠금 해제 수단이 아님 |
| 대표 장소의 화장실/취사 불가/바다 조망 | 시나리오 희망 조건을 사실로 생성하지 않음. 출처/확인일/조망 근거 확보까지 대표 시나리오 미충족. 테스트 fixture는 제품 데이터와 분리 |
| 외부 전송 금지 vs 개발 서버 | 1차 release는 로컬 전용 유지. debug loopback 서버는 개발 도구이며 제출 필수 아님. 정확한 이동 이력 외부 전송·계정·QR은 이번 범위에 넣지 않음 |
| 낮은 대비 밤 모드 vs 사용자 디자인 지시 | Pleos 토큰과 읽기 가능한 대비 우선. 밝기·차량 조명 제어 없음 |

‘권장안’은 확정값이 아니다. 문서 반영 때문에 사용자 승인으로 바꾸지 않는다. 결정에 의존하지 않는 모델·UI 구조·회귀 작업은 진행할 수 있다.

| D-10 숏폼 | debug 기능 검증 영상 존재 | 제출 홍보 숏폼 제작 결정과 별개. 이번 요청에서 제작·게시하지 않음 |

## 조건부·후속 범위

C-01 위치 지원 미확보면 출발 지역 선택을 계획하고 이를 현재 GPS로 표시하지 않는다. C-02 공조/조명 읽기 미확보면 안내·사용자 체크, C-03 시간 미확보면 ‘일몰 전 도착 권장’, C-04 에너지 계약 미확보면 시간 숫자 미노출이다. C-01/02는 지원 조사와 대체 UX를 V02-02/06에서 관리한다.

공조/조명 직접 제어·복원, QR/사진, 폰 보조 앱, 음성/Gleo, 자료 수집 자동화, 개인화, 인터뷰는 Later다. 도착 SOC·귀가/숙박/안전·밤새 공조 보장, V2L/유틸리티 실행, 12V/CO 감시, 전원 종료 후 상시 감시, 날씨·풍경 보장은 Non Goal로 유지한다.
