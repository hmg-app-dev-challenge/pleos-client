## B1/B2 및 B3 상태 변경 보호

- 명시적 미지원 배터리 카드/확인 기준/충전 규칙 숨김. 수동 입력은 정차 준비 단계에서만 제공하고 출처·입력 시각을 보존한다. 오류 새로고침은 수동 값을 지우지 않으며 유효한 차량 값이 도착하면 전환한다.
- Vehicle 2.3.2 AAR의 Exception.message 생성 코드를 확인해 정확한 오류 코드명만 분류한다. 미지원 영역/타입은 차종 미지원으로 오판하지 않고 유효하지 않은 응답으로 처리한다.
- 실제 Car UX 상태를 ViewModel에 전달해 상세 상태 변경/삭제도 차단한다. SDK 경로 알림과 배터리 갱신은 주행 중에도 처리한다. 새 여행 초기화는 화면 테마를 유지한다.
- JVM 회귀 통과, 배터리/테마 UI 4개 통과. Console SOC 20→37→20 변경을 SDK subscription으로 각각 수신했다. `verification/v211-battery/`에 증거 보존.
- 주행→불명→정차의 실제 기기 전환 행렬과 차종별 가용성은 별도 검증이 필요하다. 이를 완료로 표시하지 않는다.

## C1/C2 장소 근거와 빈 결과

공식 출처로 몽산포 지도 위치와 조건부 도킹텐트 정책, 강동 영지별 주차/취사 조건을 수집했다. 주변 풍경 필터·조건 확인 필터·빈 결과의 제외 사유·확인일/출처 링크를 구현했다. 조회일을 현장 조망 확인일로 바꾸지 않는다. JVM 장소 필터/근거 유효성 2개 추가 통과, IVI 빌드 통과. 근거는 `PLACE_EVIDENCE.md`에 보존했다. 모든 필수 조건이 확인된 대표 후보 및 현장 조망 조사는 아직 확보되지 않았다.

## D2/D3 경유 요청과 검증 한계

선택한 충전시설을 FIRST 경유지로 `requestRouteWithWaypoints`에 전달하고, 목적지 및 경유 목록을 대조한다. 선택은 스키마 6에 저장한다. 실패 시 목적지/경유지 주소를 보존한다.

실제 에뮬레이터는 경유지 이름과 남은 거리/시간을 반환했지만 좌표는 0,0이었다. 자동 좌표 일치 검증은 실패했으며 증거를 `verification/v211-navigation/waypoint.txt`에 남겼다. 이름만 일치하고 좌표가 비어 있을 때는 위치 확인 대기 상태로 전환한다. 내비 화면에서 사용자가 경유 위치를 확인한 뒤 명시적으로 확인하는 경로를 제공하며, 기록 출처는 USER다. 이 경로의 통합 테스트는 `waypoint-fallback.txt`에 보존한다. 이를 SDK 좌표 자동 검증 성공으로 보고하지 않는다.

시간 필드의 단위·충전 소요 시간 계약은 미확보이므로 정확한 출발 시각을 만들지 않는다. 이미 지난 경유지의 복귀 시나리오는 보수적으로 재확인을 요구할 수 있으며 추가 런타임 검증 대상이다.

## E1/E3 및 F1/F2 계산·기억 기록

NOAA 근사 계산을 USNO 서울 일출/일몰 자료와 5분 허용 오차로 대조하고 극야·날짜변경선 테스트를 추가했다. 자세한 범위는 `SOLAR_VALIDATION.md`에 명시했다. 준비/수면 화면에 분 단위 해의 시간 표현을 추가했으며 연속 애니메이션과 주행 중 연출은 없다.

출발 준비 시점의 일몰/다음 날 일출은 CALCULATED, 운영 근거는 REFERENCE로 보존한다. 계산 사건 시각은 실제 관측 시각과 별도 필드다. 장소 선택·충전 계획도 기록하며, 지난 기록의 확인 항목을 펼쳐 볼 수 있다. 장소 미확인 정보는 준비물 누락과 구분해 다음 여행에 표시한다. 모델/JVM 및 IVI 빌드 검증 통과. 조망 현장 조사와 전 지구 정밀 오차 보증은 하지 않는다.

## G1/G2 로컬 계획·자료·기록 동기화

계획 revision과 idempotency, 409 충돌·410 삭제, 장소/규칙 API와 AtomicFile 캐시를 추가했다. 새 자료는 다음 여행에서만 적용하며 진행 중 체크 의미를 바꾸지 않는다. 미확인/오래된 근거를 허용으로 승격하지 않는다. 완료 기록은 다운로드 추가 병합하고 삭제 표식을 양방향 전파한다. 계획 충돌 시 사용자 확인으로 새 ID를 만들며 서버 원본은 보존한다. 완료 기록 충돌은 자동 덮어쓰지 않는다.

서버 테스트 5개와 기기 캐시·마이그레이션·계획 revision·기록 병합·삭제 6개 통과 (`verification/v211-integration/storage-sync.txt`). 후속으로 시작 화면의 서버 계획 가져오기를 추가했다. 새 ID로 조건만 가져오고 완료 체크·도착·주차는 이번 여행에서 다시 확인한다. 자동 진행 상태 재개, 계정/QR 공유와 외부 배포는 미제공이다.
