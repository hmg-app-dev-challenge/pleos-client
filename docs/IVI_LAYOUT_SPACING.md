# IVI 준비 화면 간격 — 2026-11-14

기준은 [복사한 Pleos 디자인 시스템](https://www.figma.com/design/zHQP956O40m7ra3Bobyr4H/Pleos-App-Market-Design-System?node-id=7-2)이다. Foundations에는 색상·Asta Sans·그림자가 있으며 별도 전역 spacing 표는 확인되지 않았다. `18:1697` System Popup 디자인 컨텍스트의 16/24/40px 간격과 `16:293` 버튼의 16px 간격, 기존 Medium 버튼의 32px 가로 패딩을 기준으로 차Park의 레이아웃 역할을 정의했다. 다음 값은 원본의 전역 토큰이라고 주장하지 않는 **앱 레이아웃 규칙**이다.

| 역할 | 값 | 적용 |
| --- | --- | --- |
| 컨트롤 사이 | 16dp | −/+ 버튼, 취사 선택지, 준비 항목 내부 |
| 관련 내용 사이 | 24dp | 제목·설명, 카드 내부 행, 구분선 양쪽 |
| 조건 그룹 사이 | 40dp | 일정 / 동행 / 식사·잠자리 / 배터리 카드 |
| 카드 안쪽 | 32dp | 모든 여행 카드의 네 방향 |

- 여행 날짜와 철수 시각을 같은 일정 카드에 배치했다. 인원 중복 제목을 없애고 식사·잠자리와 배터리 기준을 구분했다.
- 수치 조절은 기존 Pleos Medium 버튼(최소 120×80dp, 반경 24dp)을 그대로 사용한다. `−`/`+`에는 각각 항목명을 포함한 접근성 설명이 있다. 여유가 있으면 값과 버튼을 좌우 정렬하고 좁은 창·큰 글자에서는 위아래로 쌓는다.
- 취사 선택 버튼은 동일 너비, 기존 색상·폰트·선택 상태를 사용한다. 새 이미지나 폰트는 추가하지 않았다.
- 제목·설명을 하나의 그룹으로 묶어 상위 Column의 간격에 따라 다른 항목과 분리되는 문제를 없앴다. 준비 체크 항목의 내부 간격과 구분선 여백도 통일했다.
- 실제 Pleos 화면에서는 안전 영역·시스템 바·하단 주 행동 버튼을 유지한다. 레이아웃 확대를 위해 글자나 터치 영역을 축소하지 않는다.
