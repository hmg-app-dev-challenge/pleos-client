# 차Park 제품 기획 기준 v2.1.1

개정일: 2026-11-13 · 기준: 사용자 제공 [Ver 2.1.1 원문](reference/CHAPARK_PROPOSAL_V2_1_1.md)(작성 기준 2026-11-12). [상세 변경 검토](V2_1_1_CHANGE_REVIEW.md). 파일명은 기존 링크 호환을 위해 유지한다.

차Park는 처음 가는 차박 장소의 이용 조건과 전기차 배터리 상태를 함께 확인하고, 준비·길 안내·도착·철수를 연결해 ‘내 차와 보낸 하룻밤 기억’ 카드로 남기는 Pleos 차량 앱이다. 핵심 메시지는 **내 차로 오늘 밤 — 노을에 도착해 해 뜰 때 돌아오는, 하룻밤의 작은 여행**이다. 이 문서는 목표 제품의 기준이며 구현 완료 목록이 아니다. 개발 순서는 [IVI 개발 계획](IVI_WORK_PLAN.md), 실제 완료 범위는 [구현 현황](IMPLEMENTATION_STATUS.md)을 따른다.

## 대상과 제품 구성

차박 경험·지역·동행 인원을 제한하지 않는다. 대표 사용자는 처음 가는 장소의 조건과 차량 준비를 확인하려는 전기차 운전자다. 가족 3명 시나리오를 필수로 지원하고 기존 1~2명 제한을 제거한다. 인원 수를 차량 취침 가능 인원으로 해석하지 않으며, 인원에 맞는 침구 수량과 추가 잠자리 검토를 안내한다.

핵심 경험은 차량 앱 단독으로 완주한다. 서버는 장소 근거·풍경 정보·준비 규칙·계획·기록 저장을 담당하며 차량의 로컬 저장을 대체하지 않는다. 기존 폰 앱은 유지하되 새 핵심 기능의 우선 구현 대상은 IVI다. 폰의 사전 준비·계정 연동, 기록 카드 QR 웹 페이지는 확장이다.

## 가치와 장소 데이터 수집 기준

정보 확인·재입력과 준비 부담을 줄여 기대한 풍경과 머무는 시간에 집중하도록 돕는다. 기록 카드는 안전 평가서가 아닌 확인 과정과 기억의 연결이다. 스마트폰을 ‘차량 데이터를 전혀 알 수 없는 도구’로 단정하지 않으며 별도 차량 연동·수동 확인과 서비스별 지원 차이를 설명한다.

원문은 캠핑장(48.6%), 바닷가·해변(21.1%), 산·계곡(14.6%) 선호를 데이터 수집 우선순위의 근거로 제시한다. 수치는 원문 인용이며 이번 개정의 외부 검증 결과가 아니다. 장소 유형(캠핑장/해변/산·계곡)과 풍경 유형(바다/산/강/호수/숲/도시 야경), 좋은 순간(일몰/일출/야경/별)은 분리한다. 통계상 분포에 맞춰 추천 점수나 비율을 만들지 않는다. 바다·산·강 대표 비교 요구도 그대로 유지한다.

### 출발 체크의 의미

출발 대상은 짐 싣기와 출발 전에 필요한 행동이다. 현장 확인 항목은 도착 단계로 넘긴다. 체크는 사용자의 확인 기록이며 미확인 장소 정보를 공인된 허용 상태로 바꾸지 않는다. 필수 이용 조건이 확인되지 않은 장소는 확인 방법이나 다른 장소 비교를 제공한다. 사용자 확인의 내용·시각과 장소 정보의 출처·확인일은 별도로 보존한다.

날짜·시간대·다음 날 철수 시각도 출발 조건이다. 4단계에서 모든 체크를 마쳐도 날짜가 없으면 누락 이유와 날짜 설정 동작을 제공한다. 날짜를 명시적으로 설정한 뒤 같은 의미의 체크를 유지하고 진행한다. 설정·기록·확인 팝업·입력창을 포함해 라이트/다크/밤 테마의 글자색을 맞춘다.

### 계산과 조사와 실제 사건

일몰·일출은 좌표와 날짜로 계산한 사건으로 기록한다. 실제로 노을을 관람했다거나 그 시각에 도착했다는 뜻으로 표시하지 않는다. 도착·철수 등 실제 행동 시각과 계산 시각을 구분한다. 장소의 조망 방향이 확인됐더라도 구름·계절·지형에 따른 관람 가능성을 보장하지 않는다.

NOAA 기반 계산을 제품 기준으로 한다. 현재 fractional-year 근사 구현은 적용 공식·버전·정확도·시간대·극지 예외의 기준값 대조를 완료한 뒤 인수한다. 이동 시간의 단위·기준 시각과 충전 시간의 출처를 확인하지 못하면 정확한 출발 시각 계산에 투입하지 않는다.

## 대표 사용자 흐름

집 앞 정차 → 차량 SOC와 출처 확인 → 가족 3명·취사·종료 시각 입력 → 조건을 만족한 바다/산/강 후보 비교 → 바다 × 일몰 장소 선택 → 배터리 기준에 따른 충전 검토·침구 수량·식사 변경 → 짐 싣기 체크 완료 → 충전소 경유 포함 안내 → 주행 중 핵심 상태 → 도착·주차 확인 → 수면/별 보기 밤 모드 → 일출 이후 철수 체크 → 기록 카드 → 다음 여행의 누락 준비물 우선 안내.

원문의 17:20·15:30은 예시이며 고정 데이터나 계산 결과로 사용하지 않는다. 현재 확보한 수도권 캠핑장 3곳은 내비 연결 검증용이며 바다·산·강 조건 검증을 마친 대표 후보 3곳을 대체하지 않는다.

## 출처 표시와 제품 언어

사용자 화면에 시연 배너·개발 진단·성공/실패 주입·배터리 조작 버튼을 두지 않는 기존 원칙을 유지한다. v2.1.1의 출처 표시 요구는 값 옆의 작은 정보 라벨로 반영한다: 차량 / 직접 입력 / 에뮬레이터 / 예시. 에뮬레이터 값이나 fixture를 차량 실측으로 표시하지 않는다. 영상도 에뮬레이터 값을 실차 검증으로 표현하지 않는다. 기존 화면 테스트의 개발용 문구 금지 규칙은 출처 라벨까지 금지하지 않도록 조정한다.

기록 카드는 안전 인증이 아닌 확인 기록이다. 데이터가 없으면 미확인으로 남기고 출발·철수 SOC를 현재 값으로 소급해서 채우지 않는다.

## 조건부 기능과 제외 범위

현재 위치 자동 조회, 공조·조명 상태 조회는 프로젝트 SDK 가용성과 기능별 권한·Capability를 확인한 뒤 연결한다. 위치를 못 읽으면 출발 지역 선택을 제공한다. 경로 이동 시간을 확보하지 못해도 권장 수준의 일정 안내로 핵심 흐름을 완주한다.

직접 공조·조명 제어·복원, 음성·Gleo AI, 부족한 준비물 구매 안내, QR 공유·사진 추가, 폰/계정 연동은 확장이다. **최근 소비 추세에 따른 사용자 설정 잔량까지의 예상 사용시간**은 권한과 실차 지원 확인 후 검토할 확장으로 변경한다. 핵심 기능이나 즉시 구현 확정 기능으로 편입하지 않는다.

도착 SOC 예측, 예상 사용시간의 확정값, 밤새 공조 가능·귀가 가능 여부 보장, 유틸리티 모드·V2L 실행, 12V·CO 감시, 차량 전원 종료 후 상시 감시는 계속 제외한다. 예상 사용시간 추정은 특정 공조 설정의 사용 가능 시간을 보장하는 기능이 아니다.

### 예상 사용시간 확장 관문 R14

1. Pleos 기술지원의 직접 접근 허용 범위·권한 절차·실차 지원 안내 확인. 현재 문의는 초안이며 미발송이다.
2. 허용된 일반 앱 절차로 `EV_BATTERY_LEVEL`과 `EV_BATTERY_INSTANTANEOUS_CHARGE_RATE`의 실제 값·단위·부호·상태·수신 시각·구독을 확인. 에뮬레이터 VHAL 등록을 앱 읽기 성공으로 처리하지 않는다.
3. 목표 SOC를 에너지로 환산할 근거, 현재 가용 에너지와 최근 소비 표본의 안정성 확인. 표본 부족·끊김·오래된 값·충전 중·0에 가까운 소비에서는 추정값을 숨긴다.
4. 계산 버전·표본 구간·기준 잔량·계산 시각·추정 출처를 함께 표시하는 실험안 검토. 오차 허용치와 실차 검증 기준은 모델 채택 전에 정한다. 검증 전 시간 숫자나 신뢰 범위를 임의 생성하지 않는다.

현재 직접 AAOS 조회는 `android.car.permission.CAR_ENERGY` 권한 오류로 두 속성 값을 받지 못했다. `pleos.car.permission.CAR_ENERGY`와는 별개다. deprecated SDK getter의 77400.0은 별도 원시값이며 단위 대조 전 추정에 사용하지 않는다. [진단 근거](EV_PROPERTY_REVIEW.md)를 따른다. 이 관문의 미충족은 R01~R13 핵심 흐름을 막지 않는다.

배터리 기능이 명시적으로 미지원이면 배터리 카드·충전 검토를 숨기고 나머지 기능을 제공한다. 권한 부족·통신 실패를 미지원 차량으로 판정하지 않는다. 필요할 때 수동 입력을 제공하며 출처를 보존한다.

## 검증과 제출 목표

문제 가설은 차박 입문자와 자주 다니는 전기차 운전자 각각 3~5명 인터뷰로 확인한다. 같은 장소를 기존 방식과 앱으로 준비하며 시간·누락·조작 횟수·확신을 비교한다. 재사용률은 다음 여행을 실제 떠난 이용자 중 재사용 비율, 완주율은 준비부터 기록 생성까지의 비율로 정의한다. MAU 산식은 **차박 이용 인구 × 전기차 비율 × Pleos Connect 탑재 비율 × 앱 설치율 × 월 활성 비율**로 변경한다. 각 비율의 기준 집단·기준 연도·단위를 정의하고, 계획 보급량을 현재 탑재율로 넣지 않는다. 근거 확보 전 숫자로 만들지 않는다. 사용자 검증은 확장 작업이지만 제품 효과를 이미 입증한 것으로 표현하지 않는다.

제출 목표는 실행 가능한 `apk/차박차박_차Park_release.apk`, 소스·최종 커밋, README의 실행 환경, 에뮬레이터 영상이다. 현재 데스크톱에 전달한 debug APK는 이 제출 산출물이 아니다. 에뮬레이터 값 표시를 유지하고 개발 서버 토큰·계정정보·개인정보 포함 여부를 실제 제출 전에 검사한다. 날짜와 제출 조건은 실제 제출 전에 최신 공식 안내를 별도 확인한다. 원문에 포함된 SDK 제공 상태·시장 수치·브랜드 인용은 원문 기준의 참고 주장으로 보존하며 이번 문서 개정으로 재검증된 것으로 보지 않는다. 인터뷰 연락·외부 게시·저장소 공개·제출은 이 문서 편집에 포함하지 않는다.
