차Park IVI 0.5.5 — macOS Apple Silicon 실행 패키지

필요한 환경
• M1/M2/M3/M4 등 Apple Silicon Mac
• Android SDK의 emulator와 platform-tools(adb)
• Pleos Connect API 34 ARM64 시스템 이미지(42dot)
프로젝트 소스, Android Studio 실행, Java/Gradle 빌드, Python 설치는 필요하지 않습니다.
Pleos 에뮬레이터/시스템 이미지 자체는 이 압축파일에 포함하지 않습니다.

사용 순서
1. 압축파일 전체를 푸세요. APK, command 파일, support 폴더를 함께 보관하세요.
2. 시작.command를 더블클릭하세요.
   설치된 SDK와 실행 중/기존 Pleos AVD를 찾습니다. 여러 AVD가 있으면 선택합니다.
   AVD가 없으면 설치된 시스템 이미지로 새 AVD를 만듭니다(여유 공간 10GB 이상).
   부팅 후 현재 Android 사용자에 APK를 설치하고 차Park를 엽니다.
3. 사용을 마치면 종료.command를 실행하세요. 데이터는 삭제하지 않습니다.
4. 다시 사용할 때도 시작.command를 실행하면 됩니다.

커맨드 파일
• 시작.command: 종료 상태에서는 부팅 → 설치 → 앱 실행. 실행 중이면 중복 생성 없이 재사용.
• 일시정지.command: QEMU를 멈춰 CPU 사용을 낮춤. 화면과 ADB도 멈추고 메모리는 유지됨.
• 재개.command: 일시정지된 에뮬레이터 재개. 완전히 종료됐으면 시작.command 사용.
• 종료.command: 일시정지를 풀고 정상 종료 요청. 기존 여행·AVD 데이터 유지.

SDK 경로를 못 찾는 경우
SDK_PATH.txt를 이 폴더에 만들고 첫 줄에 Android SDK 폴더 경로를 적으세요.
예: /Users/계정이름/Library/Android/sdk
ANDROID_HOME, ANDROID_SDK_ROOT 또는 기본 ~/Library/Android/sdk도 자동 인식합니다.
SDK_PATH.txt는 실행되는 코드가 아니라 경로 한 줄입니다.

최초 실행 시
• macOS가 다운로드한 command를 막으면 파일 우클릭 → 열기로 확인하세요.
  그래도 차단되면 시스템 설정 → 개인정보 보호 및 보안에서 이 파일의 열기를 허용하세요.
  보안 설정을 전체 해제하거나 sudo를 사용할 필요는 없습니다.
• Android에 USB 디버깅 승인 요청이 나타나면 확인하세요.
• 새 Pleos 사용자에서는 차량 내비 앱을 한 번 열어 초기 설정을 완료해야 할 수 있습니다.
  내비 지도/경로 검색에는 인터넷과 Pleos 서비스가 필요합니다.
• 기존 com.chapark.ivi 앱의 서명이 다르면 설치가 실패합니다. 이 패키지는 기존 앱을 자동 삭제하지 않습니다.

데이터와 로그
선택한 AVD 정보, 연결 키, 로그는 아래에 보관합니다.
~/Library/Application Support/ChaPark IVI Launcher/
새로 만든 AVD도 이 폴더에 저장합니다. 기존 AVD를 선택하면 그 AVD의 원래 데이터를 사용합니다.
폴더 선택을 바꾸려면 먼저 종료한 뒤 위 폴더의 selected-avd.txt만 삭제하세요.
실행 실패 로그: 위 폴더의 logs/emulator.log
APK 무결성: SHA256SUMS.txt (시작 시 자동 확인)
동봉한 macOS 연결 도구가 로컬 에뮬레이터와 직접 통신합니다.
기존 ADB 서버와 ~/.android/adbkey 파일은 변경하지 않습니다. 연결 도구 실행이 차단되면
support/portable-adb와 support/portable-run도 우클릭 → 열기로 확인하세요. macOS 13 이상이 필요합니다.

발열
실행 중인 Pleos 3D 차량 화면은 CPU를 계속 사용합니다.
앱을 보지 않는 동안에는 일시정지, 사용을 마쳤으면 종료를 실행하세요.
이 패키지는 앱을 다시 빌드하지 않으며 Java 빌드 데몬을 실행하지 않습니다.
일시정지 뒤 장시간 지나 서비스 연결이 회복되지 않으면 종료 → 시작으로 재부팅하세요.

지원 범위
이 실행 패키지는 Apple Silicon macOS용입니다. Intel Mac/Windows용 런처는 포함하지 않습니다.
APK는 실제 차량 권한·하드웨어 전체를 검증한 스토어 배포본이 아닌 현재 서명 프로토타입입니다.
